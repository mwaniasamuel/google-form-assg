## 📝 Quick Setup Steps

### 1. Create Form (5 min)
- Go to **forms.google.com**
- Click **+ Blank Form**
- Add form title: "Event Registration Form 2026"
- Add description

### 2. Add Questions (15 min)
- Add all fields from table above
- Set correct input type for each
- Mark required fields with asterisk
- Add validation for email and phone fields

### 3. Link to Google Sheets (2 min)
- Click **Responses** tab at top
- Click green **Google Sheets** icon
- Choose **"Create a new spreadsheet"**
- Name it: "Event_Registration_2026"

### 4. Customize (5 min)
- Click **palette icon** → Choose theme colors
- Add header image (optional)
- Click **Settings** gear → Enable:
  - ✓ Collect email addresses
  - ✓ Limit to 1 response
  - ✓ Show progress bar

### 5. Test & Submit (3 min)
- Click **Preview** (eye icon)
- Submit test response
- Check data in Google Sheets
- Share form link for assignment

## ⚡ Key Input Type Rules

**Use Dropdown for:** Long lists (countries, events, categories)  
**Use Multiple Choice (Radio) for:** Single selection (gender, payment, time)  
**Use Checkboxes for:** Multiple selections (sessions, dietary, accessibility)  
**Use Short Answer for:** Single-line text (name, email, phone, city)  
**Use Paragraph for:** Multi-line text (address, comments)  
**Use Linear Scale for:** Quantities (number of attendees)  
**Use Date for:** Date inputs (DOB)
